## 채택안 — 43상태

$$S = \{0,1,\dots,39\}\setminus\{10\}\ \cup\ \{J_3,J_2,J_1,J_0\},\qquad |S| = 39 + 4 = 43$$

| 상태 | 의미 |
|---|---|
| 0–39 (10 제외) | 해당 번호 칸에서 턴을 시작 |
| J₃ | 무인도 도착 직후 (남은 대기 3턴) |
| J₂, J₁ | 무인도 대기 중 |
| J₀ | 대기 종료, 무인도 칸에서 자유롭게 이동 가능 |
