# 보드 데이터 대조 기록

`src/markov/board.ts` 의 40칸 데이터가 어디에서 왔고 무엇이 확인되었는지를 남긴다.
남의 데이터를 그대로 받아 쓰지 않았다는 근거가 되는 문서다.

각각 208%, 200%"라고 적는다. 실험 5에서 세 정의를 분리해 재계산한다.

## 건축비 해석 — 확정

부루마불은 모노폴리와 달리 **건물을 단계적으로 업그레이드하지 않고 종류를 골라 짓는다.**
자료의 「모노폴리와의 차이점」이 "업그레이드: 부루마불은 건물 종류를 선택하는 구조,
모노폴리는 주택을 단계적으로 올려 호텔로 전환"이라고 명시하고, 「게임 방법」도
"별장을 무시하고 호텔+빌딩만 지어도"라고 서술한다.

따라서 **호텔 1채 시나리오의 투자액 = 매입가 + 호텔 건축비**다. (`investmentOf`)

## 코드에서 자동 검증되는 항목

`src/markov/__tests__/board.test.ts`

| 검증 | 근거 |
|---|---|
| 사회복지기금 접수처가 38번 | 계획서 §4.1 |
| 부에노스아이레스 21 · 스톡홀름 14 가 7의 배수 | 계획서 §4.1 |
| 2번 황금열쇠 '뒤로 3칸' → 39번 서울 | 2 − 3 ≡ 39 (mod 40) |
| 무인도 더블 탈출(4·6·8) → 스톡홀름 · 베른 · 베를린 | 10 + {4,6,8} = {14,16,18} |
| 황금열쇠 6칸 · 28번은 퀸 엘리자베스 호 | 대형 제품 기준 |
| **타이베이 풀하우스 통행료 = 37만** | 자료 서술 (3 + 9 + 25) |
| **뉴욕 풀하우스 투자액 235만 → 반액대매출 117만 5천** | 자료 각주 (35 + 20×2 + 60 + 100) |
| 베른 · 베를린 빌딩료 55 / 오타와 60 | 위 §4.3 확정 |

풀하우스 두 건은 **자료 본문의 서술값과 표의 수치를 맞물리게 하는 교차 검증**이다.
표를 잘못 옮겼다면 이 테스트가 깨진다.
