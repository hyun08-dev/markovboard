# 규칙 해석 결정표 (가정 A1–A10)

계획서 §2.3의 결정표를 코드와 함께 유지한다. 부루마불은 규칙서가 부실하고 판본·
하우스룰이 난립하므로, **무엇을 어떻게 해석했는지 밝히지 않으면 결과의 의미가
정의되지 않는다.** 가정을 밝히면 틀린 것이 아니라 정의한 것이 된다.

## 모델링 대상 선언

> 본 연구는 자산·소유권·건설·파산 동역학을 제외하고, **말 한 개의 위치 과정만을**
> 마르코프 연쇄로 모델링한다. 따라서 π 는 "게임의 정상상태"가 아니라
> **"위치 과정의 정상상태"** 이다.

## 결정표

| # | 모호한 지점 | 채택한 해석 | 근거 / 비고 | 코드 반영 |
|---|---|---|---|---|
| A1 | 더블 횟수 제한 | 제한 없음. 더블이 나오는 한 계속 재굴림 | 3연속 더블 페널티는 모노폴리 룰 | 더블 카운터를 상태에 넣지 않음 (`states.ts`) |
| A2 | 무인도 대기 | 도착 시 고립. 자기 차례마다 더블이면 탈출, 3회 실패 시 4번째 차례에 자유 이동 | 보석금 탈출 옵션은 부루마불에 없음 | `jailModel: 'split'` (J3·J2·J1·J0) |
| A3 | 무인도 더블 탈출 시 이동 | 나온 눈의 합만큼 이동하고 턴 종료 (추가 굴림 없음) | 규칙서 미기재 | `transition.ts` |
| A4 | 12번 황금열쇠 '뒤로 2칸' → 10번 | 갇힌다 | 부루마불 무인도는 도착 자체로 고립. 모노폴리의 "방문" 개념 없음 | `jailOnBackstep: true` |
| A5 | 황금열쇠 덱 추출 | 매 뽑기마다 셔플 (복원 추출) | 실제는 비복원이므로 근사임을 명시 | `cardDeck: 'shuffle'` |
| A6 | 카드 이동 후 착지 칸이 황금열쇠 | 재추첨하지 않음 (해당 턴 종료) | 무한 루프 방지 | `chainCardMoves: false` |
| A7 | 우주여행 목적지 | 기본값: 우주여행 칸을 제외한 39칸에 균등 랜덤 | 중립 기준선 | `teleportPolicy: 'uniform'` |
| A8 | 건물 개발 단계 | 기본값: 모든 개발 가능 대지에 호텔 1채 | 실전에서 가장 흔한 상태 | `buildLevel: 'hotel'` |
| A9 | 통행료 지불 대상 | 모든 대지가 상대 소유라고 가정 | 기대 지출 상한 시나리오 | `payoff.ts` |
| A10 | 사회복지기금 적립액 | 잔액을 상태에 넣지 않고 갱신보상 기대값으로 근사 | 상태공간 폭발 방지 | `payoff.ts` |
