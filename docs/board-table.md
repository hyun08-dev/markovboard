# 보드 데이터 대조 기록

`src/markov/board.ts` 의 40칸 데이터가 어디에서 왔고, 무엇이 아직 확인되지 않았는지를
남긴다. 남의 데이터를 그대로 받아 쓰지 않았다는 근거가 되는 문서다.

## 현재 출처

- 칸 배치 40칸 · 매입가 · 호텔료 · 구역별 건축비: **계획서 §4.1 · §4.2**
- 나무위키 문서(부루마불 / 주요 카드 / 게임 방법)와의 대조: **미완료** — 개발 환경의
  네트워크 정책이 namu.wiki 도메인을 차단하여 자동 조회에 실패했다 (egress proxy 403).
  대조 자료를 직접 붙여넣어 받은 뒤 이 문서를 갱신한다.

## 코드 안에서 자동 검증되는 항목

`src/markov/__tests__/board.test.ts` 가 계획서 §4.1의 교차 검증 네 가지를 테스트로 고정한다.

| 검증 | 결과 |
|---|---|
| 사회복지기금 접수처가 38번 | ✅ |
| 부에노스아이레스 21 · 스톡홀름 14 가 7의 배수 | ✅ |
| 2번 황금열쇠 '뒤로 3칸' → 39번 서울 | ✅ (2 − 3 ≡ 39 mod 40) |
| 무인도 더블 탈출(4·6·8) → 스톡홀름 · 베른 · 베를린 | ✅ (10 + {4,6,8} = {14,16,18}) |
| 황금열쇠가 6칸이고 28번이 퀸 엘리자베스 호 | ✅ (대형 제품 기준) |

## 미확정 항목 (실물 · 원자료 대조 대기)

| # | 항목 | 문서 A | 문서 B | 현재 코드 | 기본 결과 영향 |
|---|---|---|---|---|---|
| 1 | 베른 · 베를린 빌딩료 | 50만 | 55만 | 미입력 | 없음 (기본은 호텔 1채) |
| 2 | 오타와 빌딩료 | 55만 | 60만 | 미입력 | 없음 |
| 3 | 이스탄불 수익률 | 호텔가 대비 240% | 가격 대비 167.74% / 호텔가 대비 200% | — | 분모 정의 차이. §10 실험 5에서 세 정의로 분리해 재계산 |
| 4 | 대지료 · 별장료(1채/2채) · 빌딩료 전체 | — | — | 미입력 | 개발 단계 전환 실험에서만 영향 |
| 5 | 호텔 건축비 누적 여부 | — | — | `direct` 잠정 | 투자 회수 랭킹(실험 5)에 직접 영향 |

항목 1·2는 기본 시나리오가 호텔 1채이므로 **기본 결과에는 영향을 주지 않는다.**
항목 5는 실험 5의 순위를 바꿀 수 있으므로 우선 확정 대상이다.

## 금액 단위

코드의 모든 금액은 **만 원** 단위다. (`price: 5` = 5만 원)
